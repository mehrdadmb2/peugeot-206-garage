206 Garage OS سامانهٔ ثبت و تحلیل سوابق پژو ۲۰۶ SD است. ثبت رویدادها از تلگرام یا API مجاز انجام می‌شود، Cloudflare Worker آن‌ها را اعتبارسنجی و در GitHub ذخیره می‌کند و داشبورد GitHub Pages داده‌ها را به آمار، نمودار و گزارش تبدیل می‌کند.

## تغییرات شاخص نسخهٔ 3.20.0

- مدل مصرف سوخت با **سوخت‌گیری جزئی** فعال می‌شود؛ پرکردن کامل باک شرط شروع محاسبه نیست.
- موجودی بنزین باقیمانده در هر مراجعه مجهول در نظر گرفته می‌شود و با موازنهٔ ظرفیت باک، کیلومتر و حجم سوخت خریداری‌شده، بازهٔ حداقل/حداکثر مصرف محاسبه می‌شود.
- مراجعهٔ نزدیک و چندباره به پمپ به معنی خالی‌شدن باک نیست؛ تمام سوخت‌گیری‌ها در یک بازهٔ پیوسته تحلیل می‌شوند.
- تخمین مصرف و هزینهٔ سفر همراه با بازه و سطح اطمینان نمایش داده می‌شود؛ برآورد به‌عنوان اندازه‌گیری قطعی معرفی نمی‌شود.
- پیامک کامل راهور را می‌توان مستقیم برای ربات فرستاد. پیامک اصلی، فیلدهای ساختاریافته و شناسه‌های قبض ذخیره می‌شوند و ارسال دوبارهٔ همان قبض رکورد تکراری نمی‌سازد.
- مهلت پیگیری ۶۰روزه و هشدار مبلغ احتمالی دوبرابر فقط برای قبضی ساخته می‌شود که نوع آن صریحاً «دوبرگی» باشد. قبض دوربینی یا نوع نامشخص مهلت/دوبرابرشدن خودکار نمی‌گیرد.
- منطق محاسبهٔ سوخت و مهلت جریمه بین سایت، Snapshot و Worker مشترک است.

## شروع سریع

1. داشبورد عمومی را باز کن یا در چت خصوصی ربات `/start` و سپس `/guide` را بفرست.
2. برای شروع تحلیل سوخت، حداقل دو سوخت‌گیری معتبر با کیلومترشمار دقیق ثبت کن؛ لازم نیست هیچ‌کدام باک کامل باشد:

   ```text
   /fuel 12l cost=360000 toman km=432620
   /fuel 20l cost=700000 toman km=432820
   ```

3. برای ثبت قبض، متن کامل پیامک راهور را مستقیماً برای ربات بفرست؛ دستور `/fine` لازم نیست.
4. برای گزارش مصرف از `/fuelstats` و برای مشاهدهٔ جریمه‌ها از `/fines` استفاده کن.

## نکات مهم داده و امنیت

- فایل‌های `data/logs/*.json`، `data/index.json` و `data/config.json` سوابق و تنظیمات واقعی خودرو هستند؛ پیش از جایگزینی پشتیبان بگیر و داده‌های جدیدتر را حفظ کن.
- توکن تلگرام، توکن GitHub، Secretهای Worker و شناسهٔ KV در این مخزن قرار نمی‌گیرند. هنگام انتشار، Secretهای موجود Cloudflare را حفظ کن.
- سایت عمومی است؛ مدارک خصوصی خودرو از فضای خصوصی Cloudflare KV استفاده می‌کنند و به binding موجود `GARAGE_PRIVATE_KV` وابسته‌اند.
- مدل سوخت، تخمین فیزیکی مبتنی بر داده‌های ثبت‌شده است و جایگزین سنجش ECU، نشانگر واقعی باک یا مصرف اندازه‌گیری‌شده در شرایط آزمایشگاهی نیست.
- مهلت‌ها و مبلغ احتمالی جریمه صرفاً یادآور مدیریتی‌اند؛ مبلغ و وضعیت قطعی را در سامانهٔ رسمی راهور بررسی کن.

## ساختار اصلی

```text
assets/js/fuel-intelligence.mjs       موتور مشترک موازنهٔ سوخت
assets/js/fine-intelligence.mjs       موتور مشترک شرایط مهلت جریمه
assets/js/vehicle-cost-intelligence.mjs هزینه و سفر
assets/js/app.js                      داشبورد
worker/src/index.js                   ربات و API
scripts/build-dashboard.mjs           ساخت Snapshot
worker/tests/                         تست‌های رگرسیون
data/config.json                     تنظیمات خودرو و مدل‌ها
data/index.json                      فهرست ماه‌ها و نسخهٔ داده
data/logs/YYYY-MM.json               دفتر وقایع ماهانه
```

## اجرای تست‌ها در سیستم محلی

نیازمند Node.js 22 یا جدیدتر:

```bash
npm --prefix worker install
npm --prefix worker test
npm --prefix worker run check
node worker/test/smoke.mjs
node scripts/build-dashboard.mjs
```

برای جزئیات جایگزینی و Deploy، راهنمای [انتشار](docs/DEPLOYMENT-FA.md) را دنبال کن.
